简单实用的bat小脚本

| 脚本                     | 功能 |
| ---------------------- | ------------------------------ |
| generator.bat          | 生成密码、随机数...                    |
| main.bat               | 运行main.py、app.py               |
| MDTree.py              | 生成目录结构                         |
| RunNodeJS.bat          | 运行node.js脚本                    |
| RunNodeJS-HTTP.bat     | 调用node运行http服务                 |
| RunPython[python].bat  | 运行python脚本                     |
| RunPython[uv].bat      | 运行python脚本uv环境                 |
| RunPython-HTTP.bat     | 调用python运行http服务               |
| TempCleaner_Pro.bat    | 请理win系统垃圾                      |
| uv_manager.py          | 跨平台管理uv：安装、更新、卸载、镜像源、缓存路径 |
| uv_manager[linux].py   | Linux下管理uv（旧版）               |
| uv_manager[windows].py | Windows下管理uv（旧版）             |
